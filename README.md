# SecureLink-App

SecureLink is a mobile cybersecurity application that uses machine learning to analyze URLs and classify them as secure or potentially malicious. The application aims to help users identify phishing links, protect their personal information, and improve cybersecurity awareness.

## Features

- URL scanning and classification
- Machine learning-based phishing detection
- Secure user authentication using OTP
- Link history and management
- Cybersecurity awareness content
- Reports and statistics
- Admin dashboard for system management

## Technologies Used

- Flutter
- Dart
- Python
- Machine Learning
- Firebase Authentication
- Cloud Firestore
- FastAPI
- Hugging Face
- Android Studio
- Visual Studio Code

## How It Works

1. The user enters a URL into the SecureLink application.
2. The URL characteristics are sent to the phishing detection engine.
3. The Python machine learning model analyzes the URL.
4. The system classifies the URL as secure or potentially malicious.
5. The result is returned and displayed to the user.

## Project Components

### Mobile Application
Developed using Flutter to provide the user interface and mobile application functionality.

### Machine Learning Model
Developed using Python to analyze URL characteristics and classify links.

### Backend and Database
Firebase is used for authentication, data storage, security rules, and real-time synchronization.

### Deployment
The machine learning model was deployed using Hugging Face and integrated with the URL scanning functionality.
